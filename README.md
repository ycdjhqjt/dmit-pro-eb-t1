## “传家宝”保的是当期的价格，不是终身价

按 DMIT 服务条款的表述，你在某个订购周期内支付的价格，在该周期内不会变动。也就是说年付的这一年里，价格是锁死的。

但条款同时写明，DMIT 保留随时修改官网定价的权利，且不另行通知。套餐到期后，如果官网这个套餐已经涨价，续费就得按当时的新价格走。续费价等于当时官网的现行价，不是你首次下单时看到的那个数字。

这句话对“传家宝”的含金量影响很直接：它保的是这一年的价格，不是终身同价续费。看到有人说“买一次锁一辈子”，那是把年付当成了永久合约。真想降低长期成本，做法是趁低价年付把周期拉长，而不是指望几年后还能按原价续。

## 为什么传家宝专指 Pro，以及 Pro / EB / T1 的实际差别

DMIT 三条产品线的差别在线路上，不在 CPU 和硬盘上，全系都是 AMD EPYC 加企业级 SSD，不超售。

Pro 系列 IPv4 去程回程都走 CN2 GIA，IPv6 走 CMIN2/9929，三网都做了优化。公开测评给出的延迟区间是洛杉矶晚高峰对国内基本稳在 150–180ms，香港机房到大陆主要城市通常在 50ms 以内。这两组数字的意义在于晚高峰，很多便宜线路白天好看，晚上八点后就变样。

EB 系列走 CMIN2，联通一侧配 9929，对联通和移动用户更友好，电信用户也能用。它的定位是性价比，同配置比 Pro 便宜一截。

T1 是国际线路，没有针对大陆的专属优化，超量后限速 50–100Mbps 继续跑，适合大流量业务和面向海外用户的项目。拿 T1 当梯子用，体验会比 Pro 差一档，这一点得提前认。

这里有个容易花冤枉钱的地方。香港 Pro 的年付款起价 $259.9（荃湾），维多利亚 $298.88，落马洲 $358.88，而且全部缺货；月付的 HKG.Pro.TINY 是 $39.90/月，一年下来接近 $479。除非你的业务必须落地香港 IP，或者对 50ms 以内的延迟有硬需求，否则这笔钱花在洛杉矶 Pro 年付款上更合理。洛杉矶 Pro 年付的 Wee、MALIBU 才是价格和线路的平衡点，也是圈内真正被叫传家宝的那几款。

## 买之前必须知道的四条限制

**退款有三道门槛**。购买后 3 天内、流量使用不超过 30GB，可以申请全额退款，支付网关手续费要扣掉。超过 3 天但在 30 天内，可以申请按剩余价值部分退款，金额按流量使用情况或剩余时间计算，取两者中较高的那个。这条对第一次买的人很实用：3 天时间足够你把线路跑一遍，晚高峰测一次，不满意就退。

**换 IP 有条件**。Pro 和 EB 系列，IP 确实被墙的情况下每 15 天可以免费换一次；不属于被墙的其他情况，换一次 $5。T1 系列不在这条免费政策里。

**超量不停机，降速**。T1 超量后自动降到 50–100Mbps 继续用，下个月流量重置后恢复。Pro 的部分套餐同样是限速策略，表里标了 2Mbps 或 4Mbps，不会直接断网。对跑小站或者轻度代理的人来说，这比超量停机友好得多。

## 几个买完才会问的问题

**重装系统会换 IP 吗？** 不会，IP 不变，重装本身免费，后台点“重建”选系统，3 到 10 分钟完成，不需要提前关机。想换 IP 得走单独的更换流程。

**重装后 SSH 连不上怎么办？** 最常见的原因是密钥失效。重装后后台会重新生成一对密钥，旧的私钥作废，要去 SSH 金钥管理里重新生成并下载。第二个原因是本地 `known_hosts` 里存着旧的主机指纹，报 Host key verification failed，删掉对应那行或者跑一次 `ssh-keygen -R 你的IP` 就行。

**能直接用密码登录吗？** 默认不行，只支持密钥登录。后台设置的 root 密码只用于 VNC 控制台，想在 SSH 里用密码，得进系统改 sshd 配置再完整关机开机一次。

**能装 Windows 吗？** 官方后台不提供 Windows 镜像，只有 Linux 发行版。第三方 DD 脚本理论上能装，但 DMIT 的网络配置比较特殊，有用户反馈 DD 之后 IPv4 丢失，需要 VNC 手动修。没有明确需求不建议折腾。
